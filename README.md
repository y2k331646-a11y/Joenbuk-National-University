# 병원 외래 대기환자 안내 AI 챗봇 (카카오톡 × Claude)

상급종합병원 **외래 대기환자**를 위한 카카오톡 AI 안내 챗봇입니다. **카카오 i 오픈빌더**의 스킬 서버로 이 서버를 연결하면, 환자가 채널에 보낸 질문(진료 절차, 검사 준비사항, 시설 위치, 진료과 안내 등)을 Claude API가 병원 지식 기반으로 답변합니다.

> 현재는 **1단계(병원 안내)** 버전으로, 환자 개인정보·EMR 연동 없이 동작합니다. 대기순번·예약 조회 같은 개인화 기능은 병원 정보시스템 연동(2단계)에서 추가합니다.

```
사용자 ──카카오톡──▶ 카카오 i 오픈빌더 ──스킬 요청──▶ 이 서버(FastAPI) ──▶ Claude API
사용자 ◀─카카오톡── 카카오 i 오픈빌더 ◀─스킬 응답──  이 서버(FastAPI) ◀──  답변 생성
```

## 주요 기능

- **병원 지식 기반 안내** — `knowledge/` 폴더의 마크다운 문서(진료 절차, 검사 준비사항, 진료과, FAQ)를 시스템 프롬프트에 자동 병합. 문서만 교체하면 다른 병원에도 그대로 적용 가능
- **안전 가드레일** — 진단·처방 금지(진료과 안내 수준까지만), 응급 증상 언급 시 응급실/119 우선 안내, 지식에 없는 정보는 지어내지 않고 안내데스크로 연결, 개인정보 입력 자제 안내
- **바로가기 버튼** — 답변 아래 "진료 절차 / 검사 준비사항 / 진료과 찾기 / 새 대화" quickReplies 제공
- **멀티턴 대화** — 사용자별 최근 대화 기록(기본 10턴)을 기억
- **5초 제한 대응** — 오픈빌더 스킬 응답 제한(5초) 안에 동기 응답, 시간 초과 시 안내 메시지
- **AI 챗봇 콜백 지원** — 콜백 기능이 승인된 봇이면 자동으로 "먼저 접수 → 백그라운드 생성 → 콜백 전송" 방식으로 전환되어 긴 답변도 안정적으로 전달
- **긴 답변 자동 분할** — 1,000자 제한에 맞춰 simpleText를 최대 3개로 분할
- **`/새대화` 명령** — 대화 기록 초기화

## 병원 지식 관리

`knowledge/` 폴더의 `.md` 파일이 파일명 순서대로 챗봇 지식이 됩니다:

```
knowledge/
  00_병원기본정보.md   # 주소, 전화, 진료시간, 시설 위치
  01_외래진료절차.md   # 초진/재진 절차, 대기 안내
  02_검사준비사항.md   # 채혈, 내시경, CT/MRI 등
  03_진료과안내.md     # 증상별 진료과, 위치
  04_자주묻는질문.md   # 제증명, 수납, 편의시설
```

> ⚠️ **배포 전 필수**: 현재 지식 파일의 `(예시)` 표시 항목(위치, 전화번호, 규정 등)은 자리표시자입니다. 실제 병원 자료로 교체한 뒤 사용하세요. 문서를 수정하면 서버를 재시작해야 반영됩니다.

## 1. 서버 실행

```bash
# 의존성 설치
pip install -r requirements.txt

# 환경 변수 설정
cp .env.example .env
# .env 파일을 열어 ANTHROPIC_API_KEY 를 입력

# 실행
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

동작 확인:

```bash
curl http://localhost:8000/health
# {"status":"ok","model":"claude-opus-4-8"}

curl -X POST http://localhost:8000/skill \
  -H "Content-Type: application/json" \
  -d '{"userRequest":{"user":{"id":"test-user"},"utterance":"안녕하세요"}}'
```

> 카카오 오픈빌더는 **HTTPS 공개 URL**만 스킬 서버로 등록할 수 있습니다. 로컬 테스트는 `ngrok http 8000` 등으로 터널을 열고, 운영 배포는 Cloud Run / EC2 / Railway 등 아무 곳이나 가능합니다.

## 2. 카카오톡 연결 (오픈빌더 설정)

1. **카카오톡 채널 만들기** — [카카오 비즈니스](https://business.kakao.com)에서 채널 생성
2. **챗봇 만들기** — [카카오 i 오픈빌더](https://chatbot.kakao.com)에서 봇 생성 후, 위에서 만든 채널과 연결 (설정 → 카카오톡 채널 연결)
3. **스킬 등록** — 좌측 메뉴 *스킬* → *스킬 생성* → URL에 `https://<배포주소>/skill` 입력
4. **폴백 블록에 스킬 연결** — *시나리오* → *폴백 블록* 선택 → 파라미터 설정에서 위 스킬 선택 → 봇 응답을 **스킬데이터** 사용으로 변경
   - 폴백 블록은 어떤 시나리오에도 매칭되지 않는 발화가 도착하는 곳이라, 여기 연결하면 모든 일반 메시지가 Claude로 전달됩니다.
5. **배포** — 우측 상단 *배포* 버튼 클릭
6. 채널을 친구 추가하고 카카오톡에서 메시지를 보내 테스트

## 3. (권장) AI 챗봇 콜백 기능 신청

기본 스킬 응답에는 **5초 제한**이 있어 복잡한 질문은 시간이 부족할 수 있습니다. 오픈빌더 설정에서 **AI 챗봇 전환(콜백 기능)**을 신청해 승인되면, 요청에 `callbackUrl`이 포함되고 이 서버가 자동으로 콜백 모드로 동작합니다:

1. 사용자에게 즉시 "생각 중이에요" 응답
2. 백그라운드에서 Claude 답변 생성 (최대 1분)
3. 완성된 답변을 콜백 URL로 전송 → 사용자에게 도착

별도 코드 수정 없이 자동 전환됩니다.

## 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (필수) | Anthropic API 키 |
| `CLAUDE_MODEL` | `claude-opus-4-8` | 사용할 Claude 모델 |
| `HOSPITAL_NAME` | `전북대학교병원` | 페르소나와 인사말에 사용할 병원 이름 |
| `SYSTEM_PROMPT` | (미설정) | 설정 시 기본 병원 안내 페르소나를 완전히 교체 |
| `SYNC_TIMEOUT_SECONDS` | `4.2` | 동기 응답 시 Claude를 기다릴 최대 시간 |
| `MAX_HISTORY_TURNS` | `10` | 사용자별로 기억할 대화 턴 수 |

## 프로젝트 구조

```
app/
  main.py       # FastAPI 앱, /skill 엔드포인트, 페르소나, 동기/콜백 분기
  kakao.py      # 오픈빌더 스킬 응답(v2.0) + quickReplies 헬퍼
  knowledge.py  # knowledge/*.md 로더
  memory.py     # 사용자별 대화 기록 (인메모리)
knowledge/      # 병원 안내 지식 (마크다운)
requirements.txt
.env.example
```

## 다음 단계 로드맵

- **2단계**: 대기현황·예약 읽기전용 API 연동 + 카카오싱크 본인인증 (병원 정보팀 협의 필요)
- **3단계**: 예약 변경 등 개인화 기능 (보안 심의 필요)
- 개인 진료정보는 Claude를 거치지 않고 병원 API 결과를 서버가 직접 카카오 응답으로 반환하는 구조를 유지할 것

## 운영 시 참고

- 대화 기록이 **프로세스 메모리**에 저장되므로, 서버를 여러 대 띄우거나 재시작 후에도 기억을 유지하려면 `app/memory.py`를 Redis 등으로 교체하세요.
- 동기 응답 지연이 잦다면 콜백 기능을 신청하거나, `CLAUDE_MODEL`을 더 빠른 모델로 바꿔 테스트해 보세요.
- `/skill` 엔드포인트는 인증 없이 공개됩니다. 필요하면 오픈빌더 스킬 설정의 헤더 값을 검증하는 로직을 추가하세요.
