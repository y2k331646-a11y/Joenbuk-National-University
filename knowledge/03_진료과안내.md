# 진료과 안내

> ⚠️ 위치는 예시입니다. 실제 병원 층별 안내도로 교체하세요.

## 증상별 진료과 찾기 (일반 안내)

| 증상/상황 | 안내 진료과 |
|---|---|
| 감기, 발열, 소화불량, 만성질환 관리 | 내과 (호흡기·소화기·순환기 등 세부 분과) |
| 가슴 통증, 두근거림, 고혈압 | 순환기내과 |
| 속쓰림, 복통, 변비/설사 | 소화기내과 |
| 당뇨, 갑상선 | 내분비대사내과 |
| 관절통, 허리 통증, 골절 | 정형외과 |
| 두통, 어지럼증, 손발 저림 | 신경과 |
| 피부 발진, 두드러기 | 피부과 |
| 눈 관련 증상 | 안과 |
| 귀·코·목 증상 | 이비인후과 |
| 소아 진료 | 소아청소년과 |
| 산부인과 진료 | 산부인과 |
| 우울, 불면, 불안 | 정신건강의학과 |
| 소변 관련 증상 | 비뇨의학과 |
| 유방·갑상선 혹, 탈장, 수술 상담 | 외과 |

- 어느 진료과인지 애매하면 1층 종합안내 데스크에 문의하면 안내받을 수 있습니다.
- 챗봇의 진료과 안내는 참고용이며, 정확한 진료과 배정은 접수 창구/의료진 판단을 따릅니다.

## 진료과 위치 (예시 — 교체 필요)

- 내과 계열 외래: (예시) 본관 2층
- 외과 계열 외래: (예시) 본관 3층
- 소아청소년과: (예시) 어린이병원 1층
- 정형외과·신경외과: (예시) 본관 3층
- 안과·이비인후과·피부과: (예시) 본관 4층
